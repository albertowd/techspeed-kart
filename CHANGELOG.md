# Changelog

What's new in each version. Downloads are on the [releases page](https://github.com/albertowd/techspeed-kart/releases).

## [Unreleased]

## [0.1.2] - 2026-11-11

- Assetto Corsa: karts far away use simpler models, so big grids run smoother.
- Downloads keep the same file name in every version, so a new one replaces the old one.
- BeamNG.drive: delete the old `techspeed-kart-0.1.1-beamng.zip` from your mods folder when you update.

## [0.1.1] - 2026-11-11

- First version you can download.
- Fixed: version 0.1.0 had no files to download.

## [0.1.0] - 2026-11-11

- Techspeed rental karts from Velopark, Brazil, for Assetto Corsa and BeamNG.drive.
- Two versions of the kart: v2 with the steel tube protector, v1 with the rubber band.
- Three engines for each: 9, 11 and 13 hp.
- One gear and an automatic clutch, like the real karts.
- The clutch heats up if you slip it too much.
- 36 liveries per version, with worn tyres on every third kart.
- Assetto Corsa: install Custom Shaders Patch for the single gear and the clutch heat.
